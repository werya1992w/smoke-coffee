# اپ سیگار و قهوه

ثبت تعداد سیگار و قهوه همراه با قیمت، خلاصه‌ی هفته و ماه، سقف هزینه‌ی روزانه. فارسی، راست‌به‌چپ، بدون اینترنت و بدون ارسال اطلاعات به جایی.

## ساختار

- `www/` خود اپ (یک صفحه‌ی وب با ذخیره‌ی محلی)
- `.github/workflows/android.yml` ساخت فایل APK
- `.github/workflows/pages.yml` انتشار نسخه‌ی وب (برای نصب PWA)

## راه ۱: فایل APK (اپ واقعی اندروید)

1. در github.com یک مخزن (repository) خصوصی بسازید.
2. همه‌ی فایل‌های این پوشه را در آن آپلود کنید، **به‌همراه پوشه‌ی `.github`**.
   اگر آپلود پوشه‌ی `.github` از مرورگر سخت بود، با git هم می‌شود:
   `git init && git add . && git commit -m init && git branch -M main && git remote add origin <آدرس مخزن> && git push -u origin main`
3. به تب **Actions** بروید و workflow به نام **Build Android APK** را اجرا کنید (یا صبر کنید تا بعد از آپلود خودکار اجرا شود). حدود ۵ تا ۸ دقیقه طول می‌کشد.
4. بعد از سبز شدن، وارد اجرا شوید و از بخش **Artifacts** فایل `smoke-coffee-apk` را دانلود کنید. داخلش `app-debug.apk` است.
5. فایل را روی گوشی باز کنید. اگر اندروید پرسید، اجازه‌ی «نصب از منابع ناشناس» را به همان برنامه (مثلاً Chrome یا Files) بدهید.

## راه ۲: نصب از طریق مرورگر (PWA)

1. در مخزن به **Settings → Pages** بروید و Source را روی **GitHub Actions** بگذارید.
2. workflow به نام **Publish web app** را اجرا کنید. آدرس سایت در پایان اجرا نشان داده می‌شود.
3. آدرس را در Chrome گوشی باز کنید و از دکمه‌ی «نصب اپ روی گوشی» در تنظیمات اپ (یا منوی Chrome → Add to Home screen) نصبش کنید.

## نکته‌ها

- اطلاعات فقط در حافظه‌ی همان گوشی ذخیره می‌شود. حذف اپ یا پاک کردن داده‌های آن، ثبت‌ها را هم پاک می‌کند.
- قیمت هر ثبت در لحظه‌ی ثبت ذخیره می‌شود؛ تغییر قیمت در تنظیمات روی ثبت‌های قبلی اثر نمی‌گذارد.
- فایل APK از نوع debug است و برای استفاده‌ی شخصی کامل کار می‌کند. برای انتشار در فروشگاه باید نسخه‌ی release با امضای اختصاصی ساخته شود.
